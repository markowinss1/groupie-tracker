# Groupie Tracker — Visualizations

Развитие проекта Groupie Tracker: улучшенная визуализация данных и юзабилити интерфейса, построенные с соблюдением 8 золотых правил дизайна интерфейсов Шнайдермана (Schneiderman's 8 Golden Rules).

## Возможности

- Список артистов с изображениями, счётчиком найденных результатов
- Поиск артистов по имени с быстрым доступом через горячую клавишу `/`
- Детальная страница артиста: участники группы, дата первого альбома, год начала карьеры, локации и даты концертов
- Кастомные страницы ошибок (400, 404, 500) с понятными сообщениями и возможностью вернуться на главную
- Сохранение поискового запроса при переходе между страницей артиста и списком
- Обработка всех ошибок без падения сервера

## Соответствие 8 золотым правилам дизайна

1. **Единообразие** — все карточки, кнопки и блоки оформлены в едином визуальном стиле
2. **Быстрые действия для опытных пользователей** — горячая клавиша `/` для фокуса на поле поиска
3. **Информативная обратная связь** — счётчик "Найдено артистов: N" после каждого поиска
4. **Ощущение завершённости** — результат действия виден сразу и однозначно
5. **Простая обработка ошибок** — отдельные страницы для 400, 404 и 500 с понятным текстом
6. **Лёгкая отмена действий** — кнопка сброса поиска, кнопка возврата к списку с сохранением контекста
7. **Контроль пользователя** — никаких автоматических переходов или неожиданного поведения интерфейса
8. **Снижение нагрузки на память** — поисковый запрос сохраняется при переходах между страницами

## Запуск проекта

```bash
go run .
```

Сервер запустится на `http://localhost:8080`

## Запуск тестов

```bash
go test ./...
```

## Структура проекта

```
groupie-tracker/
├── main.go              — точка входа, регистрация маршрутов, запуск сервера
├── api/
│   └── client.go           — функции для получения данных с внешнего API
├── handlers/
│   └── handlers.go           — HTTP-хендлеры, обработка ошибок, логика поиска
├── models/
│   └── artist.go               — структуры данных
├── templates/
│   ├── index.html                — главная страница со списком артистов
│   ├── artist.html                 — страница деталей артиста
│   ├── 400.html                      — страница ошибки некорректного запроса
│   ├── 404.html                        — страница ошибки "не найдено"
│   └── 500.html                          — страница ошибки сервера
└── static/
    └── style.css                        — стили оформления
```

## Используемые пакеты

Только стандартная библиотека Go:
- `net/http` — веб-сервер и HTTP-клиент
- `encoding/json` — парсинг данных API
- `html/template` — генерация HTML-страниц
- `io` — чтение ответов сервера
- `strconv` — конвертация строк в числа
- `strings` — поиск подстроки при фильтрации

## Источник данных

Данные об артистах, локациях и датах концертов получены через [Groupie Trackers API](https://groupietrackers.herokuapp.com/api).
