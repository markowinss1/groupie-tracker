# Groupie Tracker

Веб-приложение на Go, отображающее информацию о музыкальных артистах через внешний API groupietrackers.

## Функционал
- Список артистов с изображениями
- Поиск артистов по имени
- Детальная страница артиста: участники, дата первого альбома, локации и даты концертов
- Обработка ошибок (некорректный ID, несуществующий артист, недоступность API)

## Запуск
​```
go run .
​```
Сервер запустится на http://localhost:8080

## Тесты
​```
go test ./...
​```

## Структура проекта
- `main.go` — точка входа, регистрация роутов
- `api/` — функции получения данных с внешнего API
- `handlers/` — HTTP-хендлеры
- `models/` — структуры данных
- `templates/` — HTML-шаблоны
- `static/` — CSS

## Использованные пакеты
Только стандартная библиотека Go (net/http, encoding/json, html/template, io, strconv, strings, os).
